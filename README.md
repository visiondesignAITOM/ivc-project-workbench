# IVC 專案工作台

IVC 專案的本機工作控制台，用來從三個角度掌握目前狀態：

- 看板：現在有哪些工作、卡在哪裡。
- 積木架構：用介面、前端、資料、後端、AI、自動化、治理安全、測試發布理解整個系統。
- 甘特圖：工作何時開始、預計何時完成、依賴哪些前置工作。
- 專案總覽：顯示四個執行階段、退出條件、關鍵路徑與里程碑。

## 本機開啟

雙擊 `start-local-workbench.command`，或在這個資料夾執行：

```sh
pnpm run dev
```

瀏覽器開啟 `http://localhost:3000/`。

## 資料保存方式

任務狀態與新增工作只保存在目前瀏覽器的 `localStorage`，不會自動上傳，也不會自動發布。清除瀏覽器網站資料或更換瀏覽器後，本機互動紀錄可能消失。

## 規劃基準

目前內建規劃根據 IVC repository 在 2026-07-26 的 `main`、TASK-097～TASK-103、公司頁擴張作業模型、平台剩餘路線圖與人工資料庫安全清單整理。候選資料完成不等於 verified、published 或 production release。

工作台以三種資料性質區分可信度：

- `已有證據`：能由任務文件、Git、測試或本機成果核對。
- `人工關卡`：阻擋狀態有文件依據，但仍需人工作出決定。
- `未來規劃`：依前置工作排出的建議工作與日期，不是已承諾時程。

架構頁不使用推估的系統完成百分比；只顯示工作台中已完成幾項、共幾項。
